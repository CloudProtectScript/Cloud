# Cloud - Spoof your Identity Anywhere, anytime.

**What is Cloud ?**

Cloud is a spoofer script but will also be a universal hub or a hub for specific games, the goal of cloud is to ensure user's privacy and delete/disable the most logging possible inside a script or an ui library.
Cloud's main UI is a fork of rayfield disabling sirius's anonymous analytics, the owner has given permissions to disable this feature by default.
